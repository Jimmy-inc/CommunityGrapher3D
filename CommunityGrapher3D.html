README
  • x y z → Cartesian, e.g. z = sin(x)cos(y)
  • r θ z → Cylindrical, e.g. r = 2 + cos(4θ)
  • ρ θ φ → Spherical, e.g. ρ = 1 - cos(φ)
  • Spell it however: rho, roh, ρ, \theta, rsinφ
  • Mixed variables → implicit surface, e.g. ρ = 2 + sin(3x)/3
  • Inequalities → shaded solid, e.g. ρ ≤ 2 and φ ≤ π/6, 1 < r < 3
  • 2D sets are drawn in the xy-plane: {(x, y) : x < 2}, {(r, θ) : r ≤ 1 + cos θ}
  • Put a matrix in front of a set to map it: A{(x, y, z) : x² + y² + z² = 1}
  • Sets: {(x, y, z) : x² + y² + z² = 1, z ≥ 0} or {(cos t, sin t, t) : t ∈ [0, 4π]}
  • Plain maths is a calculator: 1+1 shows = 2; the a/b button shows the answer as a fraction
  • Sets written with coordinates get Convert to buttons for the other coordinate systems
  • Click the empty space under the lines to add a new one
  • A = Matrix → a matrix you can edit and resize; A(cos t, sin t, 0) multiplies it by a vector
  • seq(k)(1/k, 1/(3k), 1/(2k)) → a sequence drawn as dots, one per term; set which k values under it, or press ∞ to go on forever; a line joins the terms in order (untick Connect the dots to hide it), and the first term is the bigger dot
  • Functions: f(a, b, c) = (3a, 2b, 4c), then f({(a, b, c) : a² + b² + c² = 1}) draws the image of the set; name a set with A = {…} and use f(A). Functions also work in any line, like f(cos t, sin t, t)
  • (f(t), g(t), h(t)) → curve · use u, v for a surface
  • Any other letter becomes a slider
